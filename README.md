# Écoute — французька на слух (B1)

Веб-застосунок (PWA) для тренування французької через перегляд відео з YouTube.
Без бекенду, без платних API, без реєстрації. Усі дані зберігаються у вашому браузері.

## Що всередині

| Файл | Навіщо |
|---|---|
| `index.html` | сторінка застосунку |
| `styles.css` | дизайн (світла і темна тема) |
| `app.js` | логіка відео, словника і прогресу (з коментарями) |
| `dcl.js` | розділ «Підготовка до DCL» |
| `videos.json` | **бібліотека відео** — сюди додаєте нові |
| `dcl/` | сценарії DCL, фрази і граматика (JSON) |
| `manifest.webmanifest`, `sw.js`, `icons/` | щоб застосунок встановлювався на телефон і відкривався без інтернету |

Стартова бібліотека — 35 перевірених відео (усі вбудовуються в плеєр), 3–15 хв, рівні B1–B2:
гроші та інвестиції, бізнес, наука, технології, історія, психологія, спорт, їжа і Франція зсередини, подорожі.
Канали: Le Monde, Les Echos, ARTE (Karambolage, Décryptage), Easy French, Français avec Pierre, Jamy, ScienceEtonnante, DirtyBiology, Fouloscopie, Brut та інші.
Для кожного є опис, 7–8 ключових слів з перекладом і 4–5 питань на розуміння, складені за реальним текстом відео.

## 1. Як запустити на комп'ютері

YouTube-плеєр **не працює**, якщо просто двічі клацнути `index.html` (адреса `file://`). Потрібен будь-який простий сервер.

Якщо встановлено Python — у папці проєкту виконайте:

```bash
python -m http.server 8000
```

і відкрийте в браузері `http://localhost:8000`.

## 2. Як безкоштовно викласти на GitHub Pages

**Через сайт, без програм:**

1. Зареєструйтеся на [github.com](https://github.com) і натисніть **New repository**.
   Назва, наприклад, `ecoute`, тип **Public** → **Create repository**.
2. На сторінці репозиторію: **Add file → Upload files** → перетягніть **усі файли й папки `icons` і `dcl`** з цієї папки → **Commit changes**.
3. **Settings → Pages** → у розділі *Build and deployment* оберіть **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)** → **Save**.
4. За 1–2 хвилини застосунок буде за адресою `https://ВАШ-ЛОГІН.github.io/ecoute/`.

**Встановлення на телефон:** відкрийте цю адресу на телефоні.
- Android (Chrome): меню ⋮ → **Додати на головний екран / Встановити застосунок**.
- iPhone (Safari): кнопка «Поділитися» → **На початковий екран**.

## 3. Як додати нове відео

### Спосіб А — у самому застосунку (30 секунд)
Вкладка **«Додати»** → вставте посилання YouTube → оберіть тему і рівень → **Додати**.
Назва й канал підтягуються автоматично, тривалість — коли відео вперше завантажиться.
Відео одразу отримує універсальні вправи: 3 нові слова, переказ, shadowing із записом голосу, оцінка «зрозумів на %».

Таке відео живе лише в цьому браузері (і потрапляє в експорт прогресу).

### Спосіб Б — назавжди, для всіх пристроїв
Відкрийте `videos.json` (на GitHub: файл → значок олівця ✏️) і додайте блок після останнього відео, **через кому**:

```json
,
{
  "id": "vMIed3rlZtg",
  "title": "BAGUETTE : Le Grand Mystère",
  "channel": "Jamy - Epicurieux",
  "topic": "food",
  "level": "B1",
  "duration": 460
}
```

- `id` — 11 символів з посилання: `youtube.com/watch?v=`**`vMIed3rlZtg`** або `youtu.be/`**`vMIed3rlZtg`**.
- `topic` — одне з: `money`, `business`, `science`, `tech`, `history`, `psychology`, `sport`, `food`, `travel`, `daily`, `work`, `other`.
- Для розділу DCL (необов'язково): `"dcl": "A2"` (A1/A2/B1) і `"dclTopic": "logement"` (`travail`, `logement`, `commerce`, `transport`, `sante`, `administration`, `evenement`, `societe`).
- `duration` — тривалість у секундах (9:29 → 569). Необов'язково, але без неї не працює фільтр за тривалістю.
- Необов'язково: `"about"` (опис українською), `"keywords"` (`[{ "fr": "...", "uk": "..." }]`),
  `"questions"` (`[{ "q": "...", "options": ["...", "...", "..."], "answer": 0 }]`, де `answer` — номер правильного варіанта з 0),
  `"subs"`: `"manual"` / `"auto"` / `"burned"` (субтитри вшиті в кадр).

Підказка: додайте відео способом А, а потім на вкладці «Додати» натисніть **«Скопіювати як JSON»** — готовий блок для вставки.

Перед збереженням можна перевірити, що JSON без помилок, на будь-якому «JSON validator».

## 4. Розділ «Підготовка до DCL»

Вкладка **DCL** — тренування до іспиту DCL FLE (A2–B1) і DCL FP (A1–A2) Міністерства освіти Франції:

- **Що таке DCL** — етапи, тривалість, оцінювання, відмінності від DELF (за офіційними документами).
- **12 сценаріїв** (по 4 на A1, A2, B1): робота і стажування, житло, магазин і клієнти, транспорт, здоров'я, адміністрація, організація заходу.
  Кожен: місія → документи з питаннями → аудіо (озвучує французький голос браузера) → телефонна розмова із записом голосу та зразками → письмо з лічильником слів, зразком і чеклістом → відео на ту саму тему.
- **Пробний іспит** — таймер як на справжньому DCL (повний або скорочений), без підказок; у кінці бал за кожну частину і приблизний рівень.
- **Фрази** для дзвінків і листів з озвученням і режимом карток, **граматика** A1–B1 (présent, passé composé, imparfait, futur, conditionnel) з вправами.
- **Прогрес DCL** — пройдені сценарії, пробні іспити, слабкі місця (читання / слухання / говоріння / письмо).
- На головній — кнопка **«Тренування DCL на сьогодні»**: одна частина сценарію (найслабше вміння) + 8 фраз, 15–20 хв.

Озвучення працює через системні голоси. Якщо французького голосу немає, додайте французьку мову озвучування в налаштуваннях телефона (Android: «Синтез мовлення»; iPhone: «Універсальний доступ → Усний контент → Голоси»).

### Як додати новий сценарій DCL

1. Скопіюйте `dcl/scenarios/_template.json` і дайте нову назву, наприклад `a2-banque-compte.json`.
2. Заповніть поля (підказки `_help` — прямо в шаблоні):
   - `level` (`A1`/`A2`/`B1`), `topic`, `title`, `role`, `interlocutor`, `mission` (французькою) і `missionUk`;
   - `documents` — 2–4 документи (`type`: email, annonce, affiche, horaires, menu, sms, note, fiche); новий рядок — `
`;
   - `audio` — текст, який прочитає браузер (`voice`: `f` або `m`);
   - `questions` — `part`: `lecture` чи `ecoute`; або `options` + `answer` (номер з 0), або `accept` — список правильних відповідей для введення;
   - `oral.turns` — репліки співрозмовника (`examiner`), підказка (`task`), зразок (`model`), пункти самоперевірки (`check`);
   - `writing` — завдання, `minWords`/`maxWords`, зразок (`model`), `checklist`;
   - `relatedVideos` — ID 1–2 відео з `videos.json`.
3. Допишіть назву файлу в масив `scenarios` у `dcl/index.json` (через кому).
4. Перевірте JSON на «JSON validator» і завантажте обидва файли на GitHub. Новий сценарій з'явиться одразу.

Фрази додаються так само в `dcl/phrases.json`, вправи з граматики — в `dcl/grammar.json`.

## Корисно знати

- **Прогрес** (переглянуті відео, словник, серія днів, хвилини, результати DCL) зберігається в браузері. Робіть **Прогрес → Експорт у файл**, щоб мати резервну копію або перенести дані на інший пристрій (**Імпорт з файлу**).
- **Субтитри:** застосунок просить YouTube увімкнути французькі субтитри автоматично; якщо не вийшло — кнопка **CC** у плеєрі.
- **Запис голосу** працює лише через `https://` (GitHub Pages) або `localhost`. Браузер один раз попросить доступ до мікрофона. Запис не зберігається після закриття сторінки.
- **Картки** повторюються за інтервалами 1 → 2 → 4 → 8 → 16 днів; якщо слово забули — воно повертається на початок.
- Якщо автор колись видалить відео з YouTube, застосунок покаже повідомлення — просто приберіть його з `videos.json`.
- Якщо після зміни `app.js` чи `styles.css` на GitHub зміни не видно — оновіть сторінку двічі або збільшіть номер `CACHE` у `sw.js` (`ecoute-v4` → `ecoute-v5`). Нові відео з `videos.json` і нові сценарії з `dcl/` з'являються одразу.
