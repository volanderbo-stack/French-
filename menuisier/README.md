# Menuisier FR — французька A1–A2 для столяра

Веб-застосунок без бекенду: вся логіка, дизайн і навчальний контент — в одному файлі `index.html`.
Список відео для розділу «Самопрезентація» — окремо, у `videos.config.js`, щоб його було легко редагувати.
Прогрес зберігається в браузері (localStorage).

| Файл | Що там |
|---|---|
| `index.html` | увесь застосунок: словник, відео-сцени, конструктор, діалоги, база |
| `videos.config.js` | **список відео**: анімовані персонажі, ваші mp4 і YouTube |
| `videos/` | (створіть самі) папка для ваших mp4-файлів |

## Розділи

1. **Словник столяра** — 95 слів у 7 темах (ручні й електроінструменти, вимірювання, кріплення, деревина, безпека, дії).
   Кожна картка: слово з кольоровим артиклем, переклад, озвучка fr-FR, приклад, фото або малюнок.
   Режими: картки, «вибери переклад», «напиши слово», «фото → назва», повторення помилок.
   Слово вважається вивченим після двох правильних відповідей або кнопки «Знаю».
2. **Самопрезентація** — 6 анімованих відео (столяр, будівельник, кухарка, студентка, мама з дітьми, пенсіонер)
   з рухом губ, морганням, озвучкою, субтитрами FR + переклад UA, швидкістю 0.75×/1×, повтором фрази і тестом після перегляду.
   Плюс 6 тем із питаннями та готовими фразами.
3. **Розкажи про себе** — заповнюєте поля, застосунок складає текст французькою з перекладом;
   можна прослухати й вивчити (режими «Пропуски», «Перші літери», «Лише переклад»).
4. **Робочі ситуації** — 6 діалогів (перший день, клієнт, попросити інструмент, поломка, співбесіда, дзвінок) з рольовою грою.
5. **База** — числа, розміри, кольори, дні й місяці, час — з тестами на слух.

## Як запустити

Просто відкрийте `index.html` у браузері — все, крім YouTube, працює й так.
Для YouTube потрібна адреса `http(s)://`: GitHub Pages або локальний сервер у папці репозиторію:

```bash
python -m http.server 8000
```

і відкрийте `http://localhost:8000/menuisier/`.

На GitHub Pages застосунок буде за адресою `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/menuisier/`.

## Озвучка

Використовується Web Speech API — голоси вашої системи. Якщо французького голосу немає, встановіть його:

- **Windows**: Параметри → Час і мова → Мовлення → Додати голоси → Français (France)
- **Android**: Налаштування → Спеціальні можливості → Синтез мовлення → Google → французька
- **iPhone**: Параметри → Універсальний доступ → Усний контент → Голоси → Французька

У «Налаштуваннях» застосунку можна обрати голос і швидкість. Персонажі у відео самі беруть чоловічий
або жіночий голос, якщо в системі є обидва, і говорять з різною висотою тону та швидкістю.

## Як додати або замінити відео

Відкрийте `videos.config.js` — інструкція на початку файлу. Коротко:

- **Своє mp4** (наприклад, згенероване в HeyGen, Synthesia, D-ID): покладіть файл у `videos/`,
  поміняйте в потрібному блоці `type: 'scene'` на `type: 'mp4'` і додайте `src: 'videos/назва.mp4'`.
- **YouTube**: `type: 'youtube'`, `src: 'https://www.youtube.com/watch?v=…'`.
- Щоб субтитри йшли синхронно, у кожної фрази в `script` вкажіть `t` — секунду, з якої вона звучить.
- Тест після відео — масив `quiz` (`answer` — номер правильного варіанта, рахуючи з 0).

Швидкий спосіб без редагування файлу: «Про себе» → «Додати своє відео» (зберігається лише в цьому браузері).

## Фото

Фото інструментів підтягуються з Wikimedia Commons (вільні ліцензії; автори — на сторінці «Джерела фото»).
Під кожним фото лежить SVG-малюнок: поки фото вантажиться, якщо його немає або немає інтернету — видно малюнок.
У налаштуваннях можна ввімкнути лише малюнки.
